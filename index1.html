📚 Study Notes & Explanations Repository

1. C Programming Memory & Dynamic Allocation

Dynamic memory management uses functions like malloc(), calloc(), realloc(), and free() defined in <stdlib.h>. Pointers store memory addresses of variables.

2. Projectile Motion Equations (Physics Mechanics)

Vertical displacement is calculated as $y = v_0 t - \frac{1}{2}gt^2$ using g = 10 m/s² as the standard acceleration constant.

3. Remainder & Binomial Expansion Theorems

The Remainder Theorem states that evaluating $f(a)$ yields the remainder of $\frac{f(x)}{x - a}$.
